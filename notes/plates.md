## 4. SVG の作り方（案）

- 置き場所：`assets/plates/`。ファイル名は `b03-acies-06.svg`、`b12-acies-a.svg`、`b12-p299.svg`、`b12-p344-a.svg` のように、巻と図の名前で
- 色：線と文字は `currentColor`（ページの文字色を受け継ぐ）。強調色は CSS 変数（`--plate-accent` など）で、ダークモードの値をページの CSS で切り替える。ファイル単体で開いたときのために、SVG の中に `prefers-color-scheme` の既定値も入れる
- 記号は原典の字形のまま、テキスト（`<text>`）で置く。向きを示す記号（#674 の b）は `transform="rotate(...)"` で回す
- 格子は `viewBox` の単位で1字＝1マスに置き、行・列の数は台帳どおり。スマホ幅では SVG 全体が縮むので、文字が小さくなりすぎる図（#670 など）は、ページ側で横スクロールか拡大表示を用意する
- 各ファイルに `<title>`、`<desc>`（出典：画像番号、印刷ページ、図の見出し。例「Scheffer 1664, 巻末の図 Pag.90 Acies VI（MDZ 画像 #669）をもとに作図」）を入れる
- 凡例は図の外（HTML 側）に置き、「確か／推測／不明」を区別して書く

### 4.1 試作：`assets/plates/b12-p344-acies-a-d.svg`（#675 上半分）

- 2026-10-08 作成。いちばん単純な #675（ΜΕΤΟΠΟΝ と枠の図）で型を決めた
- 原典どおりにしたこと：A の7本の線と、線ごとの1字（90度右回り）。B の枠にラベルを付けない。C の左の字は逆さ（上が Ν）、右は正立（上が Μ）。D の左2つは左回り（下が Μ）、右2つは右回り（上が Μ）。綴りは版面の ΜΕΤΟΠΟΝ（Ο はオミクロン。正しい綴りは μέτωπον）
- 変えたこと：枠の線の太さをそろえた（`<desc>` に書いた）。各図の位置関係は版面に似せたが、寸法は原典の比率を測っていない
- 色：`svg.plate { color: var(--plate-ink, #1f1d1a) }`、暗いときは `var(--plate-ink, #ece8e1)`。線と字はすべて `currentColor`
- 確かめたこと（ヘッドレス Chrome で表示）：インラインで、明るい背景・暗い背景・幅 328px（スマホの幅から余白 16px×2 を引いた幅）のどれでも読める。幅 328px では字が約10px になるので、サイト側で字の大きさを少し上げるか、図の下に拡大のリンクを付ける
- **注意：** `<img>` や `<object>` で読み込むと、ページの `--plate-ink` は届かず、色は OS の明暗の設定だけで決まる。サイトの明暗の切り替えボタンと食い違うので、**SVG はインライン（HTML に埋め込むか、JS で読み込んで差し込む）で使う**（CLAUDE.md の「図解はインラインSVG」どおり）
- PyMuPDF の SVG 表示は `<style>` の一部と文字の回転を正しく扱わないので、確認には使えない。確認は Chrome のヘッドレスのスクリーンショットで行う
