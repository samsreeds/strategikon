  - ἰλάρχης — イラルケス（第1巻第3章、第2巻第19章）
- 注
  - 注 #559：γνῶσις σημείων を "Notitia" と訳した。いわゆる索引（index）のこと。『官職要覧』（Notitia utriusque Imperii）と同じ意味
  - 注 #559：これらの記号とその由来は、命があれば別の小著『古代の記号と略号について』で論じる
  - 注 #560：記号の多くは、語全体の略字のようなもので、その意味をほのめかしている
  - 注 #560：旗の記号（ρ と τ の合字）は、コンスタンティヌス以後、軍旗ラバルム（labarum）に記されたものから取ったのだろう（プルデンティウス『シュンマクス駁論』）。リプシウス『十字架について』III.15 は、この形がマウリキオスの金貨（VICTORIA AUGG の銘、片手に球、片手に軍旗を持つ小さな勝利の女神）にもあることを示している
  - 注 #560：指揮官の記号 X は、タグマの指揮官が χιλιάρχης とも呼ばれたことから（第1巻第4章）。以下も同じ考え方
  - 注 #560：κάππα は第7巻（「指揮官が立ち、その後ろにバンドフォロス、その後ろに κάππα を運ぶ者」）と第12巻第8章第11節にも出る。シェファーは、今の言葉で mantellum、スウェーデン人がいまも cappa と呼ぶもので、雨や悪天候のときにほかの衣の上に着る長い外套と考える（頭巾 pileum が付いていたのでこの名）。ここでは指揮官の外套
  - 注 #560：ヘカトンタルコスの記号は、まず P（100を表す数字）、そこに X（ἄρχων）を書き込んだもの。次のデカルコスの I も同じで、10を表す数字（に X）
  - 注 #560：ペンタルコスの記号はシェファーの写本にない。上の例から、E（5）に X を書き込んだものだったと推測できる。また、いま欠けている次の記号（列の3番目）は、K に Γ（3）を書き込んだものだったろう。最後の K は Καβαλλάριος（騎兵）を表し、Γ は数字の印
  - 注 #561：「騎兵すなわち兵」（ἤτοι στρατιώτης）は、当時の言い方で、兵と騎兵を同じものとして扱っている
- 不確か
  - **＊印の3つ（ペンタルコス、列の3番目、騎兵）は、写本に記号がなかったので、版面では星印で代えてある**（注 #560 による）。シェファーの推測ではペンタルコスは E＋X、3番目は K＋Γ
  - **κάππα を運ぶ者とヘカトンタルコスの記号の上付き文字が、ギリシア語欄とラテン語欄で入れ替わっている。** ギリシア語欄は K^π（κάππα）と P^x（ヘカトンタルコス）、ラテン語欄は K^x と P^π。注 #560 の説明（P に X を書き込む）からすると、ヘカトンタルコスは P^x が正しく、ラテン語欄の組み違いと見られる（推測）。κάππα の K^π は「κ(άππα)」の略か（推測）
  - 最後の項の版面 ἔτι οἶδεν ἕκαστος τρακτεῦσαι の意味がよくわからない。ラテン語訳 "vel quilibet, cui imperatur" もギリシア語と対応しない。「それぞれが（武器を）扱えるとおりに」か（推測。第2巻第7章「弓を扱える者は弓兵に」と同じ τρακτεύειν）
  - 列の中の並び：この凡例からわかるのは、デカルコス（先頭）とペンタルコスが槍と盾、3番目と4番目が弓で盾なし、ということ。第2巻第7章の「前の2人と最後尾が槍、間が弓」と合う。ここで2番目がペンタルコスと読める（推測）
  - [知識] 現代の校訂版の写本には図が残っているとされ、記号も確かめられるはず。確認はしていない

### 第3巻 第2章 310人のタグマの配置（Acies I）

- 例として、**310人**（ἀνδρῶν ΤΙ）のタグマを考える
- 隊形を組んで戦いに向かって進み始めるときの図
- 進むときは間隔をあけて（ἀραιοτέρως）歩く。戦いの前に騎兵が押し合ってすり減らないように。各人が望めば自由に馬の向きを変えられるように
- 号令：**LARGITER AMBULA**（ゆったり歩け）
- こうして間隔をあけて動き、敵に向かって進む。図（καταγραφή）が示すとおり
- 注
  - 注 #561：ἀραιοτέρως は新しい意味で、πυκνῶς（詰めて）の反対か。綴りを直す
  - 注 #561：παραγγέλλει は παραγγέλλειν と書く。以下もいつもそう。どの声や合図を使うかを指示している
  - 注 #561：LARGITER について、シェファーの写本の余白に、ほかの写本では LACRITER とあり、そこから誰かが ALACRITER と推測した、と書かれている。シェファーは何も変えない。歩くときに列をゆるく保つことだから。第12巻の歩兵の戦列にも LARGIA AD AMBAS PARTES（両側へ広がれ）とある

### 第3巻 第5章 タグマの訓練のしかた（Acies IV）

- 旗（バンドン）を中心に隊形が整ったら、伝令（μανδάτωρ）が次のように告げる：**SILENTIUM. NEMO DEMITTAT. NEMO ANTECEDAT BANDUM.**（静粛に。誰も離れるな。誰も旗より前に出るな）
- タグマ単独の訓練：合図に従って動き、止まる。隊形を保って、または駆け足で（ἀπὸ δρόμου）
- **号令と合図の一覧**（本文に出る順）

| 号令（版面どおり） | 意味（本文の説明） | ほかの合図 |
|---|---|---|
| MOVE | 動け（ギリシア語 κίνησον の代わりに） | ラッパ（βούκινον）、小旗（φλάμμουλον）を振る |
| STA | 止まれ | 盾（σκουτάριον）を打つ音、手の合図、トゥバ（τοῦβα） |
| AEQUALITER AMBULA | 間隔を保ってそろって歩け（最初は広めの間隔で） | |
| AD LATUS STRINGE | 横に詰めよ。すなわちデカルコスは AD DECARCHAS、ペンタルコスは AD PENTARCHAS、テトラルコスは AD TETRARCHAS | |
| JUNGE | 横と後ろに詰めよ | |
| PERCUTE | 打て（ぶつかれ） | |
| CURSOR FESTINA | （クルソレスは）急げ。駆け足で 1マイルまで追う | |
| CUM ORDINE SEQUERE | 隊形を保ってついて行け（デフェンソレス） | |
| CEDE | 退け | |
| TORNA. MINA. | 向き直れ。押し進め | |
| DESPONE SINISTRA ／ DESPONE DEXTRA | 隊形を保ったまま左へ／右へ移れ | |
| TRANSFORMA | その場で向きを変え、後ろを正面にせよ | |
| TRANSMUTA | 旗とともに位置を移し、後ろへ回れ | |

- 横への詰め方（AD LATUS STRINGE）の詳細
  - 横に詰めるとき、片側へ寄るのではなく、全員が中央、すなわち両側からバンドフォロスに向かって寄る。メロスでも同じ。こうすると詰め方が速く整う
  - デカルコスたちが（前列で）横一線にそろうように、テトラルコスすなわち後衛（οὐραγοί）も横一線にそろわなければならない
  - きちんと詰めていれば、ぶつかり合いで誰かが遅れても、前の者たちは後ろの者に妨げられて後ろへ逃げられない
- 戦いの始まり（PERCUTE）
  - 詰めて（特に横に）進み、戦いが始まろうとするとき、PERCUTE と告げる
  - **デカルコスとペンタルコスは前にかがみ、盾で自分の頭と馬の首の一部を覆う。槍は肩の上に立てて持つ。金髪の民族（τὰ ξανθὰ ἔθνη ／ "gentes rufae"）がするように**
  - 盾の下に隠れて、隊形を保ったまま、**τριποδῳ（ラテン語訳 "solo gressu"）だけで**進む。勢いよく突進してはいけない。速さのために、組み打ちの前に隊形が崩れるのは危険だから
  - その間、後ろの弓兵が射る
- 追撃：クルソレスのように駆け足で（σὺν ἐλασίᾳ）追うか、デフェンソレスのように隊形を保って追う
  - クルソレスなら CURSOR FESTINA と告げ、**1マイル**（ἕως ἑνὸς σημείου）まで駆けて追う
  - デフェンソレスなら CUM ORDINE SEQUERE と告げ、隊形を保ってついて行く
- 少し退いて、また向き直る（退却と反転）
  - 退くときは CEDE と叫び、駆け足で**弓の射程1つか2つ分**、デフェンソレスのほうへ退く
  - それからまた TORNA. MINA. と叫び、敵に向かうように向き直る
  - これを何度も行う。正面だけでなく右や左へも。また第二線に向かっても行い、ときには第二線のすき間に入り、ときには第二線の中ほどで展開し（ἐξελίσσεσθαι）、まとまって（δρουγγιστί）敵に突進する
- 訓練では槍を横にせず上に立てて持つ。駆けるとき馬の邪魔にならないように
- 横への移動（DESPONE）：隊形を保って左右へ移る。側面防護兵と包囲兵に向いている。旗が1つならその1つが、複数なら1つが移った後、ほかも同じように旗ごとに移る
- 向きを変える（TRANSFORMA）と位置を移す（TRANSMUTA）
  - 同じ場所にとどまったまま、戦列の正面を変える。敵が不意に背後に現れたら TRANSFORMA と告げる。兵はその場で後ろを向き、バンドフォロスだけが指揮官たちとともに新しい正面（もとの後ろ）へ出る
  - 背後に大勢の敵が現れたら TRANSMUTA と告げ、旗とともに位置を移す
- 長い横隊（ἐπὶ μῆκος）だけでなく、まとまった塊（δρουγγιστί）でも訓練する
  - 長い横隊は、ぶつかり合いと押し合い（ὦσις）にしか役立たない
  - 塊で並べ、まっすぐに駆けたり、さまざまな円（κύκλοι）を描いて駆けたりする訓練も必要。まず退却と反転、次に敵への不意の攻撃、最後に助けを求める者への素早い救援
- タグマがこれに慣れれば、デフェンソレスにも、クルソレスにも、どんな必要にも向く。訓練がうまくいけば、兵は「**この9つの動き**」（διὰ τῶν εἰρημένων ἐννέα τούτων κινήσεων ／ "per has dictas novem motiones"）で、クルソレスにも、側面防護兵にも、包囲兵にもなれる
- ただし、戦列全体を敵に知られない（πουβλικίζεσθαι）ように、戦いの前に第一線と第二線をまとめて訓練したり、側面防護兵、包囲兵、塊で隠れている者、伏兵を一緒に訓練したりしてはいけない。これらは隊形というより作戦の事柄で、訓練で公にしても役に立たない。そのときの必要に応じて行う
- 旗1つ（バンドン）だけを訓練するとき
  - 大部分をクルソレスの隊形にし、10人ずつ（ἀπὸ δέκα δέκα）を、旗の両側に正面をそろえて、1段の列（ἐπὶ ἁπλῆς ἀκίας）でデフェンソレスの隊形にする
  - 正面の反対側に**10人ほど**の騎兵を置き、彼らに対してぶつかり合いを想定する
  - 旗が不意に動き出すと、クルソレスは駆け足で飛び出し、デフェンソレスから離れ、まっすぐ**1マイルか2マイル**駆け、その半分の距離まで引き返し、右へ左へとそれ、それを**3〜4回**繰り返す。それからまた円を描いて駆ける
  - その後、自分たちが出てきたデフェンソレスの間の場所へ駆け込み、デフェンソレスとともに、追ってくる敵を迎え撃つように駆ける
- モイラを訓練するときも同じ。旗のいくつかをクルソレス、いくつかをデフェンソレスにする（ときにはデフェンソレスをクルソレスにする。注 #570 の直し）。メロス、第一線、第二線も同じ
- クルソレスが円を描いて駆けるとき：旗が複数あるときは2つの指揮系統に分け、互いに反対向きに駆けさせる。一方が外側、もう一方が内側を走れば、騎兵がぶつからない
- 側面防護兵と包囲兵、およびそれと一緒に塊で隠れている者たちも、別に訓練する
  - 長い戦列には両側で長さを合わせ、回り込まれないように
  - 短い戦列に対しては回り込む
  - 同じ長さの戦列に対しては、**1つか2つの旗**ほどの少ない騎兵を正面に1段の列で並べ、包囲兵がそれに合わせて回り込み、まず翼を越え、それから一緒にいた塊が隠れて単独で不意に駆け出し、敵の背後を攻める
- これらの訓練は、単純なものも組み合わせたものも、全体のものも個別のものも、タグマをよく鍛え、隊形を敵に知られずに保つ。ほかにもいくらでも考えられる。これを書面にしてメラルケスとモイラルケスに渡す
- 平地だけでなく、通りにくい場所、高い場所、傾斜のある場所でも訓練する。暑い季節（καύσων）にも訓練するのがよい。何が起こるか誰にもわからないから
- 用語
  - μανδάτωρ — 伝令
  - ἐλασία — 駆け足、疾駆
  - δρουγγιστί — 塊になって（注 #568）
  - ἐπὶ μῆκος — 長い横隊で
  - ἁπλῆ ἀκία — 1段だけの列（注 #569）
  - ἐξελίσσεσθαι — 展開する
  - πουβλικίζεσθαι — 公になる（ラテン語 publicus から）
  - ξανθὰ ἔθνη（gentes rufae）— 金髪の民族。注 #565 によるとフランク人、ランゴバルド人など
- 注
  - 注 #562：DEONTAT と写本ははっきり書いているが、DEMITTAT と書くべき。第12巻の歩兵の部分やムルシウスの写本もそう。dimittere は「（旗を）見捨てる」こと。軍の誓約にも使われた。レオ VII.30 はこの2つの号令をギリシア語で μηδεὶς ἀφήσῃ, μηδεὶς προέλθῃ とする
  - 注 #563：MOVE は行進を命じる決まった語で、ギリシア側の軍でも使われた。以下のものもすべて同じ
  - 注 #563：「小旗を振る」の小旗は、タグマの旗ではなく、指揮官がこの用途で持っていた何らかの小旗
  - 注 #563：盾を打つ音の合図は、オナサンドロス第26章にも「手の合図か、武具を打ち合わせる音」とある。ὅπλων σύγκρουσις は盾を打ち合わせること
  - 注 #563：トゥバとラッパ（ブキナ）は別のもの。レオは「トゥバ、すなわち今の人がブキノンと呼ぶもの」「トゥバ、すなわち小さいブキノン」と言うので、大きさだけの違いのようだ。ただしシェファーはレオのこの箇所を理解できないと言う
  - 注 #563：「そろって歩く」（ἴσως περιπατεῖν）は、兵が横にも後ろにも詰めず、横列でも縦列でも正しく同じ間隔で立つこと。歩兵の戦列なら、1人が4ペーキュスを占め、詰めると2か1になる。古い戦術用語集はこれを ἁπλῶς τεταγμένον（ただ並べた状態）と呼ぶ
  - 注 #564：AD DECARCHAS の箇所は、シェファーには非常に疑わしい。著者は AD LATUS STRINGE の意味を示そうとしている（τουτέστι「すなわち」が続く）。しかし AD DECARCHAS とは何か。「デカルコスのほうへ詰めよ」なら、デカルコスは前に、ほかは後ろにいるので、横への詰め方にならない。ラテン語が落ちたか、生かじりの者がギリシア語の代わりに入れたのだろう。シェファーは「δεκάρχαι πρὸς δεκάρχας, πεντάρχαι πρὸς πεντάρχας」（デカルコスはデカルコスへ、ペンタルコスはペンタルコスへ）と書き、同じ横列に立つデカルコスどうし、ペンタルコスどうしが横に詰めることと解する
  - 注 #564：「片側へではなく」は、たとえば右だけ、左だけに寄ると、片側に空きができすぎるから。中央に向かって寄る。レオのこの箇所はひどく壊れていて欠けており、本書から直すべき
  - 注 #564：ここから、バンドフォロス（旗手）はタグマの中央に立っていたことがわかる。ただし前後左右の中心ではなく、デカルコスたち（各列の先頭）が立つ最前の横列の中央。旗は行軍でも戦列でも先頭にあったから。そのため TRANSFORMA でタグマが向きを変えるとき、バンドフォロスは指揮官とともに新しい正面に出る
  - 注 #564：PERCUTE は決まった号令。レオのギリシア語は（別の語）で、レオのラテン語訳者は FERI と訳したが、PERCUTE のほうが正しい
  - 注 #564–#565：金髪の民族は第11巻第4章の題に「金髪の民族、すなわちフランク人、ランゴバルド人、その同族と戦うには」とある。当時 "gentes rufae" と呼ばれたのはフランク人、ランゴバルド人とその近隣の民族で、髪の色から（タキトゥス『ゲルマニア』4 の rutilae comae など）
  - 注 #565：τριποδῳ μόνῳ を、レオは「τριπόδῳ μόνῳ、すなわち κάλπη と呼ばれる、ほどよい歩みで」と説明する。τριπός と κάλπη は同じもので、馬の特定の歩き方。走りながら足で3回地面を打つように見えるもの。ドイツ語の "den Dreyschlag"、イタリア語の galoppo がレオの κάλπη にあたる
  - 注 #565：CURSOR FESTINA は、シェファーの写本にはっきりそう書いてある。リガルティウスの写本は CURSOR MINA だったらしい。CURSOR を CURSU（駆け足で）に直すべきかもしれない。続く CUM ORDINE と対になるから。レオも δρόμῳ ἔλα（駆け足で進め）とする
  - 注 #565：**「1つの σημεῖον まで」**（ἕως ἑνὸς σημείου）を、レオは μιλίου（1マイル）とする。σημεῖον は道の距離を示す標識で、ラテン語の lapis（里程標）にあたる（古い語彙集「decimus lapis ＝ δέκατον μίλιον」）。したがって本書の σημεῖον は「1マイル」の意味。第7巻第7章、第9巻第2章、第10巻第15章も同じ。ラテン語訳 "ad miliare unum" はこれに従ったもの
  - 注 #566：CUM ORDINE を、レオは μετὰ τῆς τάξεως とし、レオのラテン語訳者は「戦列とともに」と誤訳した。「隊形を保って」のことで、「駆け足で」（σὺν ἐλασίᾳ、ばらばらに）と対になる
  - 注 #566：「クルソルが叫ぶ」の動詞は κράζει と書く（レオのメディチ家写本）。しかしクルソレスが号令を叫ぶというのはほかに例がない。号令は伝令の仕事。句読点が両方の本で誤っている。「クルソルが退こうとするとき」と読み、号令を叫ぶのは伝令と解する
  - 注 #566：CEDE を、レオはもっと詳しく τύπτε καὶ ὑποχώρει（打て、そして退け）とする
  - 注 #566：TORNA を、レオは στρέφου（向きを変えよ）とする。当時のラテン語で tornare は vertere（回す）の意味。ドイツ語 drehen、フランス語 tourner。「トーナメント」もここから来た
  - 注 #566：MINA を、レオは ἔλα（進め）とし、レオのラテン語訳者は contende（励め）と訳した。本来 ἐλάω は「押す、駆る」で、「向き直って、また敵を押せ、攻めよ」の意味。ラテン語の minare は agere（駆る）
  - 注 #567：訓練で槍を上に立てて持つことは、アイリアノス第32章も命じている
  - 注 #567：DESPONE を、リガルティウスは DEPONE と引くが、シェファーは本書の形が正しいと考える。レオは μετάφερε πρὸς τὸ ἀριστερόν（左へ移せ）とする。despone は「別の場所に身を置く」こと
  - 注 #567：TRANSFORMA を、レオは μετασχηματίζου（形を変えよ）とし、レオのラテン語訳者は converte と誤訳した
  - 注 #567：TRANSFORMA と TRANSMUTA の違い。TRANSFORMA では各人がもとの持ち場にとどまり、向きだけを変える（前にいた者が後ろになり、後ろにいた者が前になる）。TRANSMUTA では持ち場も離れ、バンドフォロスについて行く（前にいた者は前のまま）。だから「旗とともに移る」と言う。第15章も参照

### 第3巻 第8章 輜重を戦列のそばに置くときの全軍の並べ方（Acies VI, VII, VIII）

- 第一線（πρόμαχος）：メロスどうしは離さない。押し合わず、途切れて見えない程度に間をあけるだけ
- 図の説明（Acies VI、#221）：版面のギリシア語は「各メロスで、その兵のうち両端（ἄκρα）にクルソレス、中央にデフェンソレスを呼ぶと言う。各隊列に、**長さ17**（μῆκος ιζ′）、**深さ8**（βάθος η′）を入れる」。ラテン語訳も "quoad longitudinem quidem XVII, quoad latitudinem vero VIII"

- 軍の大きさによる第二線の形
  - **1万5千人**（πεντεκαίδεκα χιλιάδας）を超えるなら：第二線を**4つのメロス**と**3つのすき間**にするのがよい。上の図のとおり。第一線の各メロスが、それぞれ自分の避難場所を持てるように

  - メロスからメロスまでのすき間は、それぞれ、その前の第一線にいる兵の数に合わせる

  - 敵の戦列がずっと長ければ、ほかのメロスより先に中央のメロスを前に出し、両端は出さない
- 小見出し4「敵の両翼が短く、横の隊列が近づくときの敵の包み込み方」（Acies XVI）
  - 包み込み（κυκλώσεις）すなわち回り込み（ὑπερκεράσεις）をしようとするときは、メロスを少しゆっくり進ませる。メロスがぶつかる前に、両翼（κέρατα）が敵を包み込めるように
  - 逆にこちらの戦列が短くて同じように包み込まれそうなら、後に続く第二線の者たちが、包み込もうとする敵の背後に回らなければならない
- 小見出し5「長さが同じときの翼からの回り込み方」（Acies XVII）
- 注
  - 注 #571：「中くらいのとき」（ἡνίκα σύμμετρός ἐστι）は、「中くらいでないとき」（μὴ σύμμετρος）と書くべきだ。中くらいの軍は、第8章で「1万5千人から5〜6千人」と定義されているから
  - 注 #571：「〜から5へ駆け出す」の前で区切る
  - 注 #571：εὔκαιρον は εὔκαιρον χωρίον と書く
  - 注 #572：「1万5千から」（ἀπὸ μέντοι πέντε καὶ δέκα）の箇所も同じ誤り。前で区切り、また欠けている。直前に挙げた最大の数は1万2千人なので、「1万2千から1万5千〜2万人」と書くべき
- 不確か
  - **第10章の見出しの数：ギリシア語は深さ8、ラテン語訳は深さ7**（どちらも長さ9）。原寸で確認。第8章の図の説明（深さ8、ギリシア語・ラテン語とも）と合うのはギリシア語の8。第9章の図の説明は深さ7（ギリシア語）。ラテン語訳が第9章の7と取り違えたか（推測）
  - **中くらいの軍の範囲が章ごとに違う。** 第8章は「1万5千人から5〜6千人」、第10章は「2千人から5〜6千人」（第二線をメロス1つ）、第2巻第4章は「5000人から1万〜1万2千人」（第二線をメロス2つ）。注 #571 は第10章の「中くらいのとき」を「中くらいでないとき」と直して辻褄を合わせようとしている。整理すると、第二線の形は次のとおりで、境目の数は章によって少しずれる
    - メロス1つ：5千人以下（第2巻第4章、第3巻第8章）、2千〜5・6千人（第3巻第10章）
    - メロス2つ：5千〜1万・1万2千人（第2巻第4章、第3巻第10章）、5・6千〜1万5千人（第3巻第8章）
    - メロス4つ：1万・1万2千人を超える（第2巻第4章）、1万5千人を超える（第3巻第8章）、1万5千・2万人以上（第3巻第10章）
  - 小見出しの本文は短く、図（Acies XIII–XVII）に頼っている。図は #671 にあり（上の対応表）、段階3で読む

### 第3巻 第11章 全体への命令

- ローマのタグマが、それぞれこのように並べられ、訓練されたら、次にメロスも同じようにする。各メロスの指揮官を呼び集め、次の前置き（προοίμιον）を語る
- 前置きの内容
  - 狩りで追われる野ウサギ（λαγωοί）やほかの小さな獣でさえ、いつも遠くまで外へ逃げるわけではない
  - まして理性のある人間が戦うのなら、戦いでの追撃や退却を、水のように、敵や自分たちのわずかな押しで前へ後ろへと少しずつ際限なく流れ出し、危険を冒すようなやり方でしてはいけない。すべてに耐え、あらゆる方法で勝とうと努めなければならない
  - 少し押して止まるのは完全な勝利ではない。少し退いてまた向き直るのは敗北ではない。戦いの終わりがどちらかを示すので、そこを目指して戦う
- 指揮官たちが、上に述べた隊形と訓練の理由を理解し、どのような動きのためにそうするのかがわかるように、メロスごとの訓練の後で、戦列全体を一度、多くても二度並べ、その動きを通じて説明する
- 注
  - 注 #572：λαγωοί は綴りを直す（古い語彙集「λαγωός ＝ lepus」。レオ XII.74 は λαγοί）
  - 注 #572：「理解する」の語は、レオでは συνιέναι。レオのラテン語訳者は intelligentiam と訳した。本書の形が正しい
  - 注 #572：「前の」（τὰ ἔμπροσθεν）はマウリキオスの手によるものに違いない
  - 注 #572：γνωσθῇ の後で区切る

### 第3巻 第12章 第一線への命令

- 第一線（プロマコス）の指揮官たちに命じる
  - ヒュポストラテゴスが置かれる中央のメロスに従い、それと横一線にそろい（ἰσοῦσθαι）、同時にぶつかる
- ぶつかった後
  - 敵が敗走したら：クルソレスは駆け足で追撃し、**敵の陣営（φοσσᾶτον）まで**追う。デフェンソレスは隊形を保ってついて行き、止まらない。クルソレスが近くの敵に耐えられないとき、デフェンソレスのもとへ逃げ込んで立て直せるように
  - ぶつかり合いでメロスや戦列全体が押し返されたら：第二線のほうへ**弓の射程1つか2つ分**退き、また敵に向き直る。そのときは決まった声、すなわち号令（παραγγέλματα）を使う
  - 退いて向き直ったことで敵を敗走させられれば、そうする
  - 一度か二度試みても敵を押し返せなければ：第二線が近づいたとき、そこへ逃げ込み、第二線のすき間（εὔκαιρα χωρία）を通り抜け、第二線の後ろ、第二線と第三線の間の空間に入る。そこで第二線とともに展開し、まとまって（δρουγγιστί）敵を攻める。敵が逃げたら、すばやく追う
- 注
  - 注 #572：「すなわちプロマコイに」（ἤτοι προμάχοις）は、著者は προμάχου と書いたのだろう。第一線とプロマコスは同じ
  - 注 #572：ποιεῖσθαι ταύτης の間で区切る
  - 注 #572：「声、すなわち号令」（φωνῶν ἤτοι παραγγελμάτων）は、cede、feri、transmuta、clina in dextram など、戦いで命令に使った決まった言葉のこと。アイリアノスの最終章は παραγγέλματα ἡγεμονικά と呼ぶ（ロボルテッルスは praecepta と訳したが、シェファーは jussa を好む）。スエトニウスは dictata と呼んだらしい

### 第3巻 第13章 側面防護兵への命令

- 敵の翼のほうが長いとわかったら：（こちらの）翼へ急ぐ。すなわち**盾のほう（左）へ傾き**ながら、ともに伸びて長さを合わせる。メロスが敵に取り囲まれないように
- 敵の翼のほうが短ければ：**三日月の形で**（μηνοειδῶς）すばやく動き、メロスがぶつかる前に、すなわちぶつかり合いの合図が出されようとするときに、敵を包み込む
- 同じ長さなら：持ち場（διάταξις）にとどまり、デフェンソレスのようにメロスとともにぶつかる
- 注
  - 注 #572：「翼へ急ぐ」（σπεύδειν ἐπὶ κέρας）は、戦列を翼の方向へその幅だけ伸ばし、まっすぐな（ὀρθία）戦列にすること（アイリアノス第29章、第35章）
  - 注 #573：「盾のほうへ傾く」（ἐπὶ σκουτάριον κλίνοντες）は、アイリアノスの κλίνειν ἐπ' ἀσπίδα（盾のほう、すなわち左へ向く、第24章）と同じ。2つの動きがある。翼から左へ向きを変えることと、まっすぐな隊形で前へ伸びること
  - 注 #573：三日月形（μηνοειδῶς）は、アイリアノス第43章「翼が前に出て、そこに指揮官がいて、中央がくぼんだもの」。オナサンドロス第21章はシグマ形（σιγμοειδής。ギリシア文字のシグマを昔は C のように書いたので）。レオは「半円の形で」とする
  - 注 #573：「ぶつかり合いの合図」（ἡ φωνὴ τῆς συμβολῆς）は、ラッパの合図 classicum のこと（リプシウス『ローマ軍事論』IV 対話10）
- 不確か
  - [知識] 盾は左手に持つので、「盾のほう」は左、「槍のほう」は右。第14章の包囲兵は右翼にいるので「槍のほう」へ傾く（注 #573–#574）

### 第3巻 第14章 包囲兵への命令

- 敵が戦列から**弓の射程2つか3つ分**のところに来るまでは、書いたとおり隠れて右翼についていく
  - 一方のタグマは正面に、デカルコスかペンタルコスを（前列に）置く。役に立つなら、深さは**5人**で足りる（ラテン語訳 "Sufficiunt enim etiam quinque viri in latitudinem, si sint strenui"、勇敢なら深さ5人でも足りる）
  - もう一方（のタグマ）は塊（δρουγγιστί）でその後ろについていく
  - 旗、すなわち旗の頭（κεφαλάς）は、時が来るまで立てずに傾けておく。敵に見せず、気づかれないように
- 敵の翼のほうが長ければ：まず翼のほうへ、すなわち**槍のほう（右）へ**傾く。右のメロスが少しゆっくり進む間に、**弓の射程の半分**まで伸びて、敵の翼を越える
  - それからこうして傾き、回り込みながら、合図とともに、後ろに隠れていた塊を、不意に、すばやい駆け足で放つ
  - 敵が向きを変えて逃げても、逃げる者を追わず、まっすぐ立っている者たちの背後へ向かい、三日月形に包み込む
- 同じ長さなら：少し伸びて敵を越え、それから上のとおりに突進する
- 包囲兵が伸びている間に、敵も伸びて対抗しようとしたら：まだ隊形が乱れているうちに、すぐに攻める
  - 理由：翼のほうへ向きを変えるとき、敵は右側をむき出しにし、詰め方もゆるむから
- このような包み込みは、包囲兵だけでなく、メロスの指揮官も調整しなければならない。遅れすぎず、先走りすぎないように。包囲兵がぶつかり、敵が乱れ始めたら、指揮官もメロス全体を敵に向けて率いる
- 理屈：できれば敵のメロスを越えて包み込む。少なくとも長さを合わせる。敵の戦列が長ければ、包囲兵がその仕事をすることになる
- 包囲兵が必要な理由はほかにもある。前に述べたように、**むき出しの（隠れる場所のない）土地**（γυμνοῖς τόποις）でも、安全に伏兵（ἐνέδρας）を行える（ラテン語訳 "incursiones facere tuto"）
- 注
  - 注 #573：「正面に」（ἐπὶ μέτωπον）を、レオは ἔμπροσθεν（前に）とする。最前の横列に、10人の列ならデカルコス、5人の列ならペンタルコスが立つということ
  - 注 #573：「槍のほうへ」の語は、レオ XII.34「翼のほうへ、すなわち槍（κοντάριον）のほうへ傾く」。本書の κονδάριον も κοντάριον も contus（槍）のこと（ムルシウス）
  - 注 #573–#574：なぜ側面防護兵は「盾のほう」、包囲兵は「槍のほう」なのか。アイリアノス第23章「向きを変えるには、槍のほうと盾のほうの2種類がある」。槍のほうは右、盾のほうは左。側面防護兵の持ち場は左翼、包囲兵の持ち場は右翼（第2巻第4章）。だから向きの変え方が逆になる（アイリアノス第31章）
  - 注 #574：「隠れた塊」（τὸν λανθάνοντα δροῦγγον）は、包囲兵のもう一方のタグマで、上で塊で置くと言ったもの
  - 注 #574：「右側をむき出しにする」は、回り込む間、右側を守る者がいないから。戦列の外にいるので。アイリアノスも参照。そのため、そのとき詰め方もゆるむ。横向きの戦列をまっすぐに向け直すときは、いつも片側がより長く歩くことになる
- 不確か
  - 注 #574：「また多くは」（μηδὲ πάλιν）は誤り。πολύ（多く）と書く（レオもそう）
  - 注 #574：「というのは確かに」（ἐπείτοιγε πάντως）は ἐπεί τοί γε πάντως と直す（レオもそう）
  - 注 #574：「彼に」（αὐτῷ）は正しい。レオでは αὐτοὺς と書くべき
  - 注 #574：「敵が向きを変えて逃げたら」の前で区切り、後ろにコンマを置く
  - 深さ5人について：第2巻第5章の「どんなに選り抜きでも5人より浅くしない」の下限と一致する

### 第3巻 第15章 第二線への命令

- 第二線に命じる
  - ヒュポストラテゴスが置かれる中央の場所に従い（ラテン語訳 "ut locum medium, in quo stare solet hypostrategus, tueatur ipsi aptetque"）、そこに合わせる
  - ぶつかり合いの時に、第一線から**弓の射程3つか4つ分**離れているように調整する
- 敵が敗走したら：第二線はデフェンソレスとして、また助け手（βοηθός）として、隊形を保ってついて行き、止まらない
- 第一線が押し返されたら：（第三線のタグマを通って、下の不確かを参照）苦しんで逃げてくるメロスを受け入れ、第一線の者たちとともに攻める。隊形を保ち、乱れて敵を追わない
- 第一線の戦いが一進一退（ἀμφίβολος）で、追撃と逆追撃が繰り返されるとき
  - 待って、事の成り行きを見守る
  - **2回か3回、吠えるような叫び（βρυχμώδεις）**を上げ、戦う味方を励まし、敵をおびえさせる
  - 急いで第一線と混ざったり、近づきすぎたりしない。混乱が起き、みっともない敗走が続かないように
- 第二線も、よくあるように押し返され、後衛すなわち第三線のところまで来たら：自分で立て直すよう努める
- 伏兵による背後からの攻撃が報告されたら
  - 少数なら：第三線が自分の者を送るので足りる
  - 足りなければ：隊形のとおり、前の者たちが向きを変え、旗が指揮官とともに後ろへ移り、両面向き（ἀμφίστομος）の戦列としてうまくぶつかる。敵が向きを変えたら、後衛（旗1つか2つ）が追う
  - 大勢なら：TRANSMUTA と告げ、デカルコスたちがタグマごとに後ろへ来て、そこがメロスの正面になる
- 全員に一般的に命じる：第一線で敗走が起きても、第二線の誰も前に出てはいけない
- 注
  - 注 #574：「彼に置かれる、従う」（τάσσεσθαι αὐτῷ, πείθεσθαι）の区切りは誤り。τάσσεσθαι の後にコンマを置く。この章の内容はすべてレオ XII.90 にもあるが、レオのラテン語訳者は理解しなかった
  - 注 #574：「大勢なら」の「οἱ δὲ πολλοί」は εἰ δὲ πολλοί と直す
  - 注 #574：「そして悪く」（καὶ κακῶς）はつながらない。κἂν κακῶς（たとえ悪くても）などと書く
- 不確か
  - **「第三線のタグマを通って」か「第一線の」か。** 版面のギリシア語は「それ（第一線）が第三線のタグマを通って押し返されたら」（τρέπηται διὰ τῶν τῆς τρίτης τάξεως ταγμάτων）と読める。ラテン語訳は "Quod si vero & ipsam vertant hostes in fugam, ut retrocedat versus tertiae aciei tagmata"（敵が第二線をも敗走させ、第三線のタグマのほうへ退いたら）で、主語を第二線と取っている。注 #574：レオでは「第一線の」（τῆς πρώτης）とあるが誤りで、本書から直すべき
  - 版面の訳の主語がギリシア語とラテン語で食い違う箇所が多く、この章は読みに自信がない。上の要約はギリシア語を主に、ラテン語訳で補った
  - [知識] 第2巻第15章では、ストラテゴスが第二線の中央に立つ。この章の「ヒュポストラテゴスが置かれる中央の場所」は、第二線の中央の位置合わせの基準を言っている（推測）

### 第3巻 第16章 伏兵への命令

- 伏兵、すなわち敵の戦列への奇襲に向かう者たちに命じる
  - 何より先に偵察兵（σκοῦλκαι）を前に送る。敵に出くわしたとき、全員がまとめて敵につかまったり、敵の戦列の側面や背後で敵の伏兵に遭ったりしないように
- 敵もよく2つの戦列に並ぶ。注意しないと、第一線を攻めているうちに、こちらが敵の伏兵に遭う
- 敵も同じように2つの戦列に並んでいたら：敵の第一線の背後ではなく、その端、すなわち翼を襲う。前に述べたとおり、メロス1つに対しても、2つに対しても
- 攻撃の時機の調整：こちらの戦列より早すぎず、遅すぎず、両軍の戦列が**弓の射程2つか3つ分**離れたときに、伏兵に向かった者が敵を攻める
- 訓練がきちんとできていれば、そのときにこれらの命令は必要ない。これらはすべてタグマの訓練の中で身についている
- 注
  - 注 #574：「出くわさないように」（ἵνα μὴ ἡ ἀπάντημα）の ἡ は何か。εἰς と書いたのかもしれない。レオはここを省いている
  - 注 #574：「その端、すなわち翼」（τῷ ἄκρῳ αὐτῆς, ἤτοι κέρατι）。戦列の端と翼は同じ。レオも同じように説明する。「戦列の端」と「翼の端」は違う（第2巻第1章）
  - 注 #574：「命令の」（μανδατόρων、伝令の）は疑わしい。μανδάτων（命令の）と書くべき。伝令の話ではなく、各戦列への命令の話だから（前の章の題もそう）。あるいはラテン語をまねて mandatorum の意味か
  - 注 #574：τεταγμένων は προστεταγμένων（命じられた）と書くべき（レオもそう）

  - MOVE、STA、LARGITER AMBULA、AEQUALITER AMBULA、AD LATUS STRINGE、JUNGE、PERCUTE、CURSOR FESTINA、CUM ORDINE SEQUERE、CEDE、TORNA、MINA、DESPONE SINISTRA／DEXTRA、TRANSFORMA、TRANSMUTA、SUSCIPE、SILENTIUM、NEMO DEMITTAT、NEMO ANTECEDAT BANDUM
  - ラテン語の号令、意味、使う場面、シェファーの注とレオのギリシア語の言い換え。読者がラテン語の号令を声に出して読めるよう、カタカナも付ける
- **TRANSFORMA と TRANSMUTA の違い**（第5章、注 #567）：2コマずつの図。TRANSFORMA は各人がその場で後ろを向き、旗手だけが新しい正面へ出る。TRANSMUTA は旗とともに全体が位置を移し、前列は前列のまま
- **AD LATUS STRINGE の詰め方**（第5章、注 #564）：両側から中央の旗手に向かって寄る動き。デカルコスどうし、テトラルコスどうしが横一線にそろう
- **PERCUTE の突撃姿勢**（第5章）：前にかがみ、盾で頭と馬の首を覆い、槍を肩に立てた騎兵の図。後ろから弓兵が射る
- **クルソレスの訓練の動き**（第5章）：駆け出して1〜2マイル → 半分戻る → 右へ左へ3〜4回 → 円を描く → デフェンソレスの間へ戻る、の軌跡図。円を描くときに2組が内と外を逆向きに走る図も
- **側面防護兵と包囲兵の動き**（第10章の小見出し、第13・14章）
  - 敵が長い・短い・同じ長さの3つの場合に分けた図。側面防護兵は盾のほう（左）へ、包囲兵は槍のほう（右）へ
  - 包囲兵の隠れた塊が敵の背後に回り、三日月形に包む動き
- **第一線の敗走から立て直しまで**（第12・15章）：第一線が弓の射程1〜2つ分退いて向き直る → だめなら第二線のすき間を通り抜け、第二線と第三線の間で展開 → 第二線とともに攻める。第二線は弓の射程3〜4つ分後ろで待ち、2〜3回叫ぶ
- **軍の規模と第二線の形の対応表**（第8・10章、第2巻第4章）：章ごとに境目の数がずれていることも示す
